# Remake

Creator's Remake tool and `/creator/remake` app link open the shared private hosted
workflow. The same account projects, cut list, shot versions, quotes and downloads
are available on web and mobile. It uses the existing Maboroshi session and payment
bridge; provider credentials stay on the server.

Use a 3–15 second reference with audio and one or two subject images. Review the
reference, detect/correct its cuts, save up to eight shots, then confirm generation
per shot. Completed shots can be revised independently and assembled with the
original soundtrack. Short shots are billed for padded provider duration; padding
is removed from the assembled result. Assembly has no extra generation charge.

An uncertain paid submission cannot be blindly repeated. Confirmed saved provider
requests can be collected without a new generation. The native download guard
accepts only signed files from the hosted service. iOS keeps the existing purchase
flag and supports saved-project viewing/downloads when purchases are disabled.

This is a JavaScript-only release. No native modules or runtime version changes
are required. The hosted worker release must be deployed before publishing OTA.
The result is a downloadable edit; automatic editor/library import is not included.
