# Maboroshi discovery and presets

Open Creator, select Video, and search the model picker for Maboroshi. Kling
Character Swap and Motion Control use the same picker and arm their matching
reference templates. Switching to a different model clears a clip-workflow
template so it cannot accidentally become the next generation's prompt.

Maboroshi uses the shared hosted interface at https://live.dehub.io/maboroshi/,
also embedded by https://dehub.io/creator/maboroshi. Its 180 original look
directions, 20 categories, search, reference guidance and selection behavior are
maintained in dehubweb's services/maboroshi/static. Do not copy a second catalog
into the app. The creator provides a reference showing the selected look.
These directions are curated ideas rather than a measured popularity ranking.

Preset selection does not submit or pay for a job. Storefront purchase controls,
project ownership, clip review and the existing stage payment bridge still apply.
Restricted storefronts can browse the catalog and view saved projects; they
cannot apply directions or purchase processing. Verify the picker on Android
and iOS after the corresponding update is published.
