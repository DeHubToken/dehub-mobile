# RIFTN brand downloads

The icon is the three-part symbol used by web and mobile navigation, not the R from the wordmark. Legacy filenames containing `dehub` do not establish a different icon.

The full logo is the RIFTN wordmark, including its raised TM. Do not substitute the old DEHUB wordmark from `/brand/wordmark-*.png`.

Public downloads at https://dehub.io/docs/brand-assets offer black and white PNG and SVG files:

| Asset | PNG | SVG |
| --- | --- | --- |
| Black icon | /brand/riftn-icon-black.png | /brand/riftn-icon-black.svg |
| White icon | /brand/riftn-icon-white.png | /brand/riftn-icon-white.svg |
| Black full logo | /brand/riftn-wordmark-black.png | /brand/riftn-wordmark-black.svg |
| White full logo | /brand/riftn-wordmark-white.png | /brand/riftn-wordmark-white.svg |

Icon SVG paths come from the existing web `public/brand-icon.svg`; only the fill is fixed for each colour. Icon PNGs are copied unchanged from `public/brand/mark-*.png`. Full-logo PNGs are copied unchanged from `public/brand-kit/brand/riftn-logo-*.png`. Full-logo SVGs contain those original PNGs as embedded images: they preserve the artwork but are not vector outlines. Never trace, redraw, or substitute a font when supplying these originals.

Mobile uses the same icon in `assets/web-icons/dehub-logo-center.png` and the RIFTN wordmark in `assets/web-icons/riftn-wordmark-white.png`. Download links share the production web assets so both platforms use the same files.
