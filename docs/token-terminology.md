# Token terminology

Use **tokens** for the DeHub currency in balances, prices, purchases, tips,
rewards and user instructions. Use `assets/web-icons/dehub-coin.png` for the
gold coin and the localized token name for its accessible label.

`tokenLabel()` formats display text while preserving other currencies such as
USDC. Keep the original currency symbol in transaction arguments, API fields,
token registries, contract calls, search aliases and stored records.

Keep **DHB** when explaining the on-chain ticker, documenting contracts, showing
cashtag examples or quoting historical announcements. General instructions
should say tokens. The app's docs links open the shared documentation at
`https://dehub.io/docs`; its page and crawler copy are maintained in dehubweb.
