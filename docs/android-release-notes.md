Android 1.18.4 restores the original animated welcome intro for new installations. The three full-screen slides introduce DeHub, followed by the swipe-to-start bar and sign-in screen.

The restored intro is included in the APK, so it is available on the first launch without waiting for an over-the-air update. The existing loading splash stays in place.

Install this APK over the existing DeHub installation. No uninstall or data clearing is required.
